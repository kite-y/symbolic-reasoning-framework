## 从塔罗实验中抽取出的，可迁移式符号关系规则

注意：以下为我自定义的含义/代表（可更改）
基础属性：
阴性——柔性，防御，被隐藏的，被动的，背面，内在的，精神层面的，虚幻的
阳性——刚性，攻击，被公开的，主动的，正面，外在的，现实层面的，真实的
中性——平衡，虚实同存，刚柔并济，攻守兼备

极——极端状态
衰——微弱状态
性质：分为——较清晰/具象性质与较模糊/抽象性质
锚点——元素的核心含义/代表，固定不变（但可偏移）

偏见——锚点、属性、性质由使用者自定义，规则并不为客观真理

适用于：任何有可换为“元素”的领域（理论可行）
不适用于：精确度要求高、确定性任务等

核心在于可模糊性——处理为建议/自主选择/自主决断等；在于模糊与可定义之间交界点
